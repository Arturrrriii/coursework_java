КУРСОВАЯ РАБОТА: КАЛЬКУЛЯТОР МЕТАЛЛУРГА, ВАРИАНТ 2

1. ЧТО НАХОДИТСЯ В АРХИВЕ

start.bat — запуск готовой программы в Windows.
build.bat — повторная компиляция исходного кода в Windows.
test.bat — запуск автоматических проверок.
start.sh — запуск в Linux с графическим интерфейсом.
build/metallurg.jar — скомпилированная программа; build/tests — скомпилированные тесты.
lib — зависимости SQLite JDBC и PDFBox, необходимые для работы.
src/main/java/metallurgy — исходный код, каждый класс находится в отдельном файле.
src/test/java/metallurgy — исходный код проверок.
data/example.csv — пример файла для импорта.
docs/Пояснительная_записка.docx — текст курсовой работы.
docs/02_Для_защиты.txt — объяснение работы и ее ограничений.

2. УСТАНОВКА И ЗАПУСК В WINDOWS

1) Скопируйте ZIP на компьютер. Нажмите по архиву правой кнопкой → «Извлечь все». Не запускайте программу из открытого окна ZIP.
2) Установите JDK 21 или новее. В командной строке Windows выполните: java -version
   Если команда не найдена, добавьте папку bin установленной JDK в системную переменную PATH или переустановите JDK с включенной настройкой PATH. После этого откройте новую командную строку.
3) В извлеченной папке дважды щелкните start.bat. Первоначальное подключение к интернету для приложения не требуется: зависимости уже включены в архив.
4) Введите логин из 3–32 латинских букв, цифр или символа подчеркивания и пароль не короче 8 символов. Нажмите «Регистрация», затем «Войти». Запомните пароль: функции восстановления нет.
5) Программа сохраняет базу в папке пользователя Windows: %USERPROFILE%\MetallurgCalculator\metallurg.sqlite. Для резервной копии закройте программу и скопируйте этот файл. Для удаления учетных записей и данных достаточно после закрытия программы удалить этот файл; предварительно сделайте копию.

3. ПРОВЕРКА РАБОТЫ

1) Откройте вкладку «Расчет». Уже введен учебный пример: 200 т, глубина 1,6 м, q = 3,2, 4 сопла, марганец 0,6 %, угол 30°, коэффициент 1,15.
2) Нажмите «Рассчитать». Ожидается диаметр 5,507 м; высота 8,164 м; объем 170,837 м³; удельный объем 0,854 м³/т. «Сохранить расчет» добавляет запись в базу.
3) Откройте вкладку «Проверки процесса» и нажмите «Проверить»: пример должен показать глубину проникновения с учетом наклона около 1,207 м, допустимый интервал глубины около 1,507–1,689 м и минимальную высоту цилиндра около 1,225 м. Исходные значения этой вкладки относятся к примеру 200 т и при другом режиме должны быть заменены.
4) Перейдите в «История», оставьте значение 100 и нажмите «Сгенерировать». Появятся учебные записи. Щелчок по заголовку сортирует строки; поле поиска, переключатели и флажок фильтруют таблицу. Выделенную строку можно удалить или перенести в форму.
5) «Файл» → «Импорт CSV» → data/example.csv. Формат: UTF-8; разделитель «;»; первые семь колонок — mass_t, depth_m, intensity_m3_t_min, nozzles, manganese_percent, angle_deg, slag_factor. Десятичный разделитель — точка или запятая. Проверка проводится до добавления; если возникает ошибка записи базы, часть строк может быть уже импортирована.
6) Меню «Файл» позволяет экспортировать все записи текущего пользователя в CSV, XLSX и отчет PDF, а также сохранить график в PDF. Фильтр таблицы на экспорт и график не влияет. Экспорт содержит основные расчетные результаты; дополнительные проверки струи и газа в записи и отчет не сохраняются.
7) Для проверки кода откройте test.bat. Сообщение «Все проверки пройдены» означает успешные проверки модели, пароля и базы с 100 записями.

4. КАК ОТКРЫТЬ ИСХОДНЫЙ КОД В INTELLIJ IDEA

Установите IntelliJ IDEA Community и JDK 21+. Откройте File → Open и выберите извлеченную папку проекта. В File → Project Structure → Project выберите JDK. В Project Structure → Libraries добавьте JAR из папки lib; src/main/java назначьте Sources Root, src/test/java — Test Sources Root. Откройте класс metallurgy.Main и нажмите зеленый треугольник возле main. Для самостоятельной пересборки из командной строки можно запустить build.bat (требует доступности javac и jar в PATH). Не перемещайте metallurg.jar без папки lib.

5. ПОЯСНИТЕЛЬНАЯ ЗАПИСКА

Откройте DOCX в Microsoft Word или LibreOffice Writer. На титульном листе заполните ФИО, группу, подписи и даты, проверьте данные кафедры. После добавления скриншотов проверьте номера страниц в содержании и при необходимости исправьте их вручную. Вставьте собственные скриншоты в отмеченные места и проверьте переносы страниц перед сдачей.

6. СУЩЕСТВЕННЫЕ ОГРАНИЧЕНИЯ

В отдельном списке вариантов вариант 2 — расчет параметров конвертера; в общем ТЗ старое распределение относит к варианту 2 еще материальный и тепловой балансы. В проекте реализован вариант по отдельному списку. Уточните противоречие у преподавателя: если он требует оба баланса, их нужно будет дополнительно реализовать.
Модель учебная: сечение ванны — усеченный конус, глубина задается вручную, расчеты струи и газов основаны на введенных данных. Значения по умолчанию не являются универсальными производственными параметрами. Расчет не заменяет инженерное проектирование.
