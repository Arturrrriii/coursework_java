КРАТКОЕ ОБЪЯСНЕНИЕ ДЛЯ ЗАЩИТЫ

Цель работы — разработать на Java Swing информационную систему, которая рассчитывает параметры кислородного конвертера, хранит исходные данные, позволяет сравнивать результаты и формировать отчеты.

В расчете выбрана одна из двух форм ванны, приведенных в пособии: перевернутый усеченный конус. Сначала определяется приближенный объем ванны из массы и коэффициента. Из объема конуса рассчитываются диаметры. По интенсивности продувки, числу сопел и содержанию марганца находится свободная высота; затем — горловина, высоты частей и объемы. Отдельная вкладка проверяет проникновение струи и минимальную высоту цилиндра.

На примере 200 т программа дает D ≈ 5,507 м и V ≈ 170,837 м³. В решенном примере пособия D ≈ 5 м и V ≈ 146,6 м³: в пособии там используется вторая форма сечения — конус с шаровым сегментом, а здесь — первая. Плюс в самом пособии на с. 25 есть расхождения в коэффициентах и на с. 22 и 26 — различие формулы летки. Для данной модели сопоставлять нужно с расчетом по тем же формулам, а не требовать полного совпадения двух разных геометрий.

ООП: классы разделяют расчет, интерфейс, хранение данных, экспорт и график. Swing обрабатывает действия кнопок, нажатия меню и выбор таблицы; SQLite хранит пользователей и исходные параметры. Результаты пересчитываются из исходных параметров при чтении. Это предотвращает рассогласование, но после изменения формул старые записи пересчитаются по новой версии модели.

Пароли: соль формируется случайно для каждого пользователя; применяется PBKDF2-HMAC-SHA256 с 210 000 итераций; база содержит соль и хеш, а не исходный пароль. Это хеширование, хотя в задании сказано «шифрование». Доступ к файлу базы должны ограничивать средствами ОС.

Тесты проверяют диаметр, свободную высоту, граничные значения, струю, пароль и 100 записей SQLite. Фактически выполненные проверки перечислены в записке. Размещение в GitHub пользователь выполняет самостоятельно: существующий репозиторий не подключен и история разработки не создана.

Снимки для отчета: 1) окно входа без личного пароля; 2) вкладка «Расчет» с результатами; 3) вкладка «Проверки процесса»; 4) вкладка «История» со 100 записями; 5) вкладка «График»; 6) экспортированный XLSX или PDF; 7) окно test.bat с успешным результатом.
